# Coverage-question cheat sheet (synthetic training; lowest conflict tier)

Use only when it does not conflict with regulation or a current official payer source. If it conflicts, the official source wins.

| Question | Must distinguish | Cite |
|---|---|---|
| Are they covered today? | Date of service, product, effective/term dates | Current official eligibility source |
| Will the claim pay? | Eligibility ≠ payment guarantee | DOC-FED-HETS-NO-GUARANTEE |
| Are we in network? | Eligibility ≠ network | DOC-FED-HC-NETWORK |
| Do they need a referral? | Eligibility ≠ referral | DOC-SYN-PCP-REFERRAL |
| Is prior auth done? | Eligibility ≠ authorization | DOC-FED-PRIOR-AUTH-CMS |
| Who pays first? | COB/MSP order | DOC-FED-COB-OVERVIEW |
| What is the copay? | Only if current official source states it | DOC-FED-HC-DEDUCTIBLE |
| Portal is down | Unavailable, not inactive | DOC-SYN-DOWNTIME |
| ER / urgent emergency | Do not delay screening | DOC-FED-EMTALA-CMS |
