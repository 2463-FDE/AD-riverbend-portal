06 · Right tool, right job

When to choose Chroma

Main selling point

A purpose-built vector database

  • Vectors are first-class, not bolted onto a relational engine
  • Dev-first ergonomics — pip install, embed & query in a few lines
  • Batteries included — embedding fns, metadata filtering, collections
  • Laptop → distributed / serverless with no app rewrite
Domains & use-cases where it wins
  • AI-native / greenfield RAG — no existing Postgres to inherit
  • Devtools & code search, agent long-term memory
  • E-commerce recommendation, media / content platforms
  • Scale-first — 100M–billions of vectors, high throughput
  • Multimodal image / audio / text retrieval
  • Data is non-regulated — SOC 2 suffices, no PHI/PCI

Rule of thumb: Chroma when the vector store is the primary system; pgvector when vectors are a feature of an app already sitting on Postgres. Riverbend is the latter.

06 · The recommendation, in one paragraph

Rationale

recommended

For Riverbend’s document-retrieval feature we recommend pgvector, inside the Postgres instance we already run. The deciding factor is compliance posture, not raw performance: as a HIPAA covered entity, every store that touches patient records must sit inside a business-associate relationship and a known data-residency boundary. Postgres on managed RDS/Aurora is already HIPAA-eligible under the AWS BAA and already carries our encryption, access-control, and audit posture, so the embeddings and their source PHI never leave the compliance boundary we already operate. Managed Chroma, by contrast, advertises only SOC 2 Type II with no HIPAA BAA and runs as a multi-tenant cloud service in fixed regions (us-east-1 / eu-west1) — routing PHI there would open a new, uncontracted data path and a residency question we cannot answer. Chroma’s advantages are real but orthogonal to our need: they appear at 100M–billion-vector scale, and Riverbend’s corpus is clinic-scale, comfortably inside pgvector’s single-node HNSW envelope. pgvector is therefore the lowest-cost, lowest-ops, and — decisively — the only compliant option today.

HIPAA business-associate coverage + data residency decide it; scale does not.Rationale
